# SOBRE O PROJETO (SEMENTES DO AMANHÃ)
A ONG Sementes do Amanhã é uma organização fictícia criada para o desenvolvimento de atividades acadêmicas.  
O site foi construído com base nos princípios de semântica, acessibilidade e design limpo, servindo como base para futuras evoluções com CSS e JavaScript.

## ENTREGAS REALIZADAS

(EXPERIÊNCIA PRÁTICA I)
- Estrutura semântica completa com header, nav, main, section, article, aside, footer, implementada nas páginas index, projetos e cadastro;
- Input HTML5 no formulário de cadastro e máscaras de input (CPF, CEP, telefone);
- Uso de tags hierárquicas de títulos (h1 a h3) corretamente estruturadas;
- Acessibilidade: atributos alt, label for, aria-label e navegação lógica;
- SEO básico: uso de meta description, keywords e author;
- Favicon configurado e ícones sociais;
- Organização de pastas (/img, etc.);
- Códigos validados pelo W3C.
